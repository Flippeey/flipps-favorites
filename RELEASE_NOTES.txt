What's new in 2.5.0:

- Persona templates in onboarding: the setup wizard detects how you organise your bookmarks and suggests ready-made Workspaces with matching view and sort layouts
- Per-Workspace view and sort: each Workspace now remembers its own view mode and sort order independently
- More Workspaces: the cap is raised to 20, with Alt + arrow keys and a desktop jump-menu for fast switching
- Create a Workspace from a folder: promote any folder to a full Workspace from its right-click menu, or by dragging it onto the Workspace bar
- Icon search shows its source: hover an icon search result to see where it came from

Improvements:
- Simplified the Appearance background picker
- Clearer Workspace settings drawer with preview cards and consistent headers

Fixed:
- Faster icon fallback on sites that redirect to insecure (http) addresses, with no more console spam
- Resolved a sync-storage limit that could be hit with many Workspaces
- A default Favorites Workspace is now created when you skip onboarding
- The "Remember last workspace" setting is now honoured on startup
- Cleaner drop indicators when dragging folders onto the Workspace bar
- More accurate layout density defaults on wide and high-resolution displays

Removed:
- The unused contain/cover icon fit control
