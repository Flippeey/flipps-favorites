What's new in 2.7.0:

- Add bookmarks and folders straight into any folder with the new destination picker in the add dialogs
- Undo folder delete and batch delete right from the toast
- New "Move to..." and "Open all in tabs" context-menu actions
- Opt-in custom icons for folders
- Hero search now opens typed URLs directly and falls back to web search when there are no matches
- QuickAdd now warns when you're about to add a duplicate bookmark
- Replay the onboarding setup anytime from Help, or open Help with the ? shortcut
- Fixed: wallpaper at 100% opacity no longer leaves a dark tint
- Fixed: Firefox new-tab page now shows the correct branded favicon
- Fixed: drag no longer breaks on bookmarks or folders with special characters in their name
- Fixed: settings that fail to save now show a toast instead of silently reverting
