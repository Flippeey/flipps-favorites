What's new in 2.8.0:

- New setting: show the item count on folder tiles always, or only on hover
- Menus and dropdowns are fully keyboard-operable, and settings controls are labelled for screen readers
- "Open all in tabs" now opens tabs one at a time and tells you if any failed
- Fixed: "Move to..." no longer offers a selected folder or its own subfolders as the destination
- Fixed: undoing a move restores the items in their original order
- Fixed: workspace shortcuts no longer fire while a dialog or folder is open; middle-click works inside folders too
- Fixed: leaving system theme mode keeps the theme that was showing
- Fixed: the new-workspace and Quick Add dialogs can no longer be submitted twice
- Fixed: Firefox icon searches and downloads no longer fail when the background page goes to sleep
- Fixed: Chrome icons no longer fail to load after the background restarts mid-fetch
